## 🚀 Sobre Mim

**Fundador do CobrançaAuto** – o SaaS brasileiro que automatiza cobranças via WhatsApp com pagamento 1-click integrado ao Stripe.

Estou construindo uma plataforma multi-tenant que resolve um problema crítico para PMEs: **inadimplência e tempo gasto em cobrança manual**. O CobrançaAuto orquestra todo o ciclo de billing – desde a emissão da cobrança até o pagamento, com notificações inteligentes via WhatsApp e checkout simplificado.

### 🎯 Background Técnico

Engenheiro de Machine Learning com pós-graduação em IA/ML e graduação em Análise e Desenvolvimento de Sistemas. Especializado em:

- 🤖 **Agentes de IA Autônomos** - Desenvolvimento de agentes para orquestração de fluxos complexos
- 🔐 **Cibersegurança** - Detecção de ameaças em tempo real via ML aplicada
- ⚙️ **MLOps** - Pipelines completos (CI/CD, monitoramento, A/B testing)
- 📊 **Resultados** - Modelos em produção com 92% de accuracy processando 10k+ predições diárias
